# Keynote 实现手册

课程为旧版 Keynote。以下是在当前本机需要先定位并验证的界面操作路径，名称以实际界面为准。课程依据详见 course-index。可编辑原生对象优先；不支持的操作用可控状态页作为替代，改变页数需向用户交代。

## 静态操作

| 目标 | 对象及操作 | 核验 |
|---|---|---|
| 对齐与等分（05） | 多选同类对象→排列/Arrange→对齐左/中心/右、顶部/中部/底部；分布水平或垂直。必要时在排列栏输入同一宽高和 X/Y | 边缘和中心线对齐；分布在至少三件对象上检查间隙；图片锁定纵横比 |
| 层级（07） | 先放背景和主图，承托矩形设填充，置于文字后、主图前。在排列中前移/后移/置前/置后，锁定不需移动的背景 | 文字完整、色块不挡主体、没有意外露出 |
| 字体（09–12） | 选文本→格式/文本，设置字体、字号、颜色、字重、行距；项目符号设置缩进和标记尺寸/颜色 | 放映机字体、混排基线、行尾、符号距离 |
| 取色（13） | 选文字或形状→颜色选择器→吸管，点击实际主色；调节明暗保持文字对比 | 同类语义颜色一致；灰度或远看仍可辨 |
| 图片（14–15） | 选图→图像/编辑遮罩，调整裁切框与图位置；即时 Alpha 去简单背景；复杂轮廓用透明 PNG；形状填充、边框和阴影仅在需要时用 | 真实比例、无锯齿、无主体误删、放映清晰 |
| 形状（19） | 插入形状，关闭填充、设描边，或用钢笔绘制路径；线与箭头按真实方向布局 | 高亮圈精准但不遮字；曲线及节点描述正确关系 |
| 图表（18） | 插入图表→编辑数据，核对源列、系列、轴和标签，再调颜色与线宽；用样式复制统一同类元素 | 用原始数据反查关键值，检查轴起点、单位、图例、标签 |

## 构建、动作与过渡的分工

- Build In：对象进入。Action：对象在页内变化。Build Out：对象退出。
- Transition：页间切换。相邻页面有相同对象且大小/位置变化时使用 Magic Move／神奇移动。
- 每个构建记录：对象 ID（页面＋可识别名称）、操作类别、效果、持续时间、方向、延迟、触发、预期状态。用 Build Order／构件顺序检查总链。
- On Click／点按时由主讲人控制节拍。With Previous／与上一构建同时用于同一时刻的动作。After Previous／上一构建后用于串行。若有 delay，考虑上个动作时长和延迟的合成；实际测试而不是仅按参数推算。
- 多个对象需独立动作时分别加入构建并设置同时触发；若它们在视觉上组成一个实体、同步做同一个动作，则可成组。如组内仍需单独动画，先测试是否适用。

## 配方 A：当前讲述焦点与恢复总览（06）

适用四个或更多并列要点。课程示例用约 10% 不透明度，不是所有背景都适配该比例。起始若需预览总览，可在前一页显示所有内容或以先总览再淡出安排；本配方起始隐藏未来对象。

| 点击 | 构建链 | 观众看到 |
|---|---|---|
| 1 | 项 A Build In: Appear | A 清晰，B/C/D 隐藏 |
| 2 | B Appear，A Action: Opacity 约10%，With B | B 清晰、A 淡 |
| 3 | C Appear，B Opacity 同时 | C 清晰、A/B 淡 |
| 4 | D Appear，C Opacity 同时 | D 清晰、A/B/C 淡 |
| 5 | A/B/C Opacity 恢复100%，后两项 With 首项 | A–D 清晰总览 |

Keynote 选择对象→动画效果→构建出现／动作→添加效果，在构件顺序面板重排触发。若当前版本无法设置目标 opacity，可用复制状态页，固定对象坐标并改变颜色/不透明度，硬切或短叠化。验收五步及回退，确保未来内容未提前展示，结束页可读且无残留淡化。如果已讲点仍是必要计算条件，保持可读的中低强调，不可淡到不可辨。

## 配方 B：总览—局部—同一总览（08、22）

创建总览 G，所有角色或主题有稳定位置。复制一页 A，保留将要讲的对象的原生身份，移动/放大到叙述位置，其他对象淡化或移出画布；设置 G 到 A 的神奇移动。重复复制回到 G 的位置，保持对象一致，不重新插入长得相似的图像。再进入 B。若实际版本因文本或对象类型匹配失败，使用原生形状或同一图像复制重排，匹配类型选对象；预览观察同一物件是否真正移动而非被替换。

检查：G→A→G→B→G 共五状态能辨认共同锚点；A/B 的展开有明确口播触发；每个转场方向合理，画外对象进入不会造成错误路径；重复回到 G 时坐标一致。速度按实际讲述试听；课程没有给出通用最优秒数。

## 配方 C：模拟真实动作（20、21、28）

案例手机背夹电池：先建立手机前景层、背夹后景层、最终装配层。独立选择后景背夹设 Move In，由对应方向移入；最终图层以适合的出现/叠化接替，测试叠合无穿帮。实际资产必须与所讲物体一致。数学几何的平移、旋转同理，但必须保持精确关系，不能靠手拖改变题意。

动作动机对照：
- 文字说明：Appear 或无效果；不让句子无缘由落地或弹跳。
- 棒球示意：真实运动方向及弹跳有内容动机；别把物体当装饰。
- 门、书页、水滴：专用过渡仅在当前画面确有门、页或水纹语义时用；书先放大到页面填充再翻页。
- 较小标记：退出效果受对象比例、上下文影响，不机械复制发布会例子。

## 配方 D：声画同步与视频（16、17）

对齐目标声与视觉事件，而非对齐开场与整段音效。用本地合法文件，优先短剪辑。将音频文件插入目标页，在格式/音频或动画构件顺序检查播放触发；如果能与动作同时或延迟触发，按视觉落点调整。开门的声音应匹配金属或木门材质，落地声对应实际碰撞瞬间。先用静音预览核对画面，再用有声放映检查是否有提前、滞后、重复或盖住人声；没有实测音轨不可宣称同步通过。

视频：拖入或插入本地视频，选择自动或点按播放，按需要剪切预览范围；设置适当的首帧，提前说清观看目的。返回普通幻灯片后接回口播。验证无断链、声画完整、切页不会突然重新播放。另设备需确认媒体权限和文件嵌入状态。

## 配方 E：倒计时与串行动画（24、26）

课程作业用两个共位数字槽，逐个数字通过显示/消失与构建顺序组合。转录示例 0.8s 显示与 0.2s 消失之和一秒；具体需要观看完整播放，尤其两位数交界 10→09。建议先做 15→00，先验证 15→14 的单步，再 10→09 的两槽并发，再连续验证完整链。版面上保留所有数字可编辑，避免外观相似但错位。若采用独立计时视频作为替代，明确它与原生动画的不同；用实际时间戳验证总时长。第26集告知旧作业曾纠正过，须以「新」版为参考，不复用错误参数。

## 配方 F：版本与替代

旧版 Smart Builds 曾能组合图片旋转、推送和洗牌（26），后续被移除。不要假定现代软件存在此菜单，重新设计为独立 Build、成组、连续状态页或神奇移动，并验证实际放映。若要转 PPTX，先确认用户接受转换，再比对字体、构建、过渡、备注、媒体；原生 .key 作为主交付。静态预览不能证明动画或音频。对现场低幕使用实际安全线，重新排布重要内容。
